# 제주 설화 OCR 및 E-book 데이터 분석 보고서

## 개요 (Executive Summary)

이 폴더에는 **2,156개의 JSON 파일**을 포함한 대규모 제주 설화 데이터셋이 포함되어 있습니다. 동일한 콘텐츠가 서로 다른 소스와 품질로 제공되는 두 개의 주요 폴더를 분석했습니다:

- **`ebook/`**: 제공업체에서 제공한 고품질 정제 데이터
- **`ocr/`**: 자체 OCR 처리로 생성한 데이터

- **W_** 접두사: Web/기타 (ebook: 824개, ocr: 291개)

## 🔍 동일 콘텐츠 품질 비교

### ebook 폴더 (제공업체 데이터)
**✅ 장점:**
- 완벽한 한글 인식 (OCR 오류 없음)
- 체계적인 메타데이터 구조
- 정제된 텍스트와 표준화된 포맷
- 즉시 사용 가능한 품질

**예시: `ebook/ebook_C_F_001.json`**
```json
{
  "title": "개와 닭의 원한",
  "content": {
    "text_cleaned": "사람들이 닭을 길러서 잡아먹는 데에 비해...",
    "char_count": 860
  }
}
```

### ocr 폴더 (자체 OCR 데이터)
**❌ 주요 문제점:**
- 심각한 한글 인식 오류: "닭을" → "닭올", "개를" → "개틀"
- 누락된 문자와 잘못된 변환
- 제주어 방언 인식 정확도 매우 낮음
- 추가 전처리 필요

**예시: `ocr/C_F_001.json`**
```json
{
  "content": {
    "full_text": "사람들이 토종닭올 3년 이상 기르고 개틀 7년..."
    // 다수의 OCR 인식 오류 포함
  }
}
```

## 📈 콘텐츠 유형별 분석

### C_ (Content/해제) 파일 특성
- **목적**: 설화 해제, 분석, 교육적 설명
- **언어**: 표준 한국어
- **길이**: 평균 800-1,100자
- **활용**: 일반 사용자 교육, 요약 정보

### T_ (Text/원문) 파일 특성
- **목적**: 제주어 방언 구술 채록 원문
- **언어**: 제주 방언 + 표준어 혼재
- **길이**: 평균 2,000-3,000자
- **활용**: 언어학 연구, 문화 보존

**제주어 방언 예시:**
```
"계불과삼년(鷄不過三年), 닭은 삼년을 더 기르믈 허믄..."
"너허곡 나허고는 가근하다. 그러니, 주인놈이 괴약헌 놈이라..."
```
